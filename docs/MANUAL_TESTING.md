# Manual testing guide

Automated tests cover the detector, scoring, DOM discovery, blocking/restoring, settings and the content controller (`npm test`). This checklist covers what needs a real browser.

## Setup

1. `npm install`
2. `npm run build`
3. Chrome → `chrome://extensions` → enable **Developer mode** → **Load unpacked** → select the **`dist`** folder.
4. In a second terminal: `npm run demo` and open <http://localhost:5173/demo.html>.

> After changing code: `npm run build`, then click the reload ↻ icon on the extension card and reload the test tab.

## 1. Detection and blocking (demo page)

| Step | Expected |
| --- | --- |
| Open the demo page | The “Ultimate Guide to Content Marketing” article and the `helpful_helper` comment are replaced by placeholder cards (“Highly likely AI-generated content blocked · Confidence: NN%”). |
| Look at the human article, `casual_carl` comment, code block, cookie text, form | All untouched. |
| Toolbar icon | Badge shows `2`. |
| Click **Show content** | Original content reappears with a slim “— shown · Hide again” bar. |
| Click **Hide again** | Placeholder returns. |

## 1b. No flash of AI content

| Step | Expected |
| --- | --- |
| Reload <http://localhost:5173/demo.html> several times | The AI article and AI comment are **never** visible, not even for a moment — the placeholder is there from the first paint. |
| Open <http://localhost:5173/demo.html?slow> (streams the page in 6 chunks, 300 ms apart) | The page builds up piece by piece; AI text never appears, human text appears as it arrives. |
| DevTools → Performance → record a reload | No long tasks from the extension; its work shows up as short (<16 ms) slices during parsing. |

## 2. Dynamic content & SPA navigation

| Step | Expected |
| --- | --- |
| Click **Load AI-style comment** | The new comment appears directly as a placeholder — its text is never shown. |
| Click **Load human comment** | Stays visible. |
| Click **Simulate SPA navigation** | URL changes (`?page=…`); the new AI comment is blocked. |

## 3. Popup

| Step | Expected |
| --- | --- |
| Open the popup | “Protection ON”, hostname, *AI content detected / Blocked / Visible* counts that update live. |
| **Show All** / **Block All** | All placeholders reveal / re-block; counts update. |
| **Scan Page** | Re-scans (counts stay consistent). |
| Move the **Sensitivity** slider | Label changes (Very low … Very high); setting persists after reopening the popup. |
| **Disable on This Site** | Page restores immediately; button becomes **Enable on This Site**; status “Paused on this site”. Click again to re-enable. |
| Toggle the **ON/OFF** switch | OFF restores every tab and greys the toolbar icon; ON re-scans. |
| Open the popup on `chrome://extensions` | “Not available on this page”. |
| Open a tab *before* loading the extension, then open the popup there | “The blocker isn’t running in this tab yet” with **Activate on this page** — clicking it starts scanning. |
| Click **Support on PayPal** | PayPal opens in a **new tab**; the current page is unchanged. |

## 4. Options page (right-click the icon → Options, or popup → Settings)

| Step | Expected |
| --- | --- |
| Switch blocking behavior to **Blur / Collapse / Hide** | Open demo tab updates live. Blur: click blurred text to reveal. Collapse: “Expand” bar. Hide: content disappears (restore with popup → Show All). |
| Raise **Confidence threshold** to 99 and sensitivity to Very low | Fewer / no blocks on the demo page. |
| Disable **phrase** and **style** detection | Nothing is blocked. |
| Add `127.0.0.1` / `localhost` to the **Whitelist** | Demo page restores; nothing is scanned. |
| Add it to the **Blacklist** instead | Popup status: “strict mode for this site”. |
| Reload the options page | All values persist. |
| **Test the detector** → *Try an AI-style sample* | Score, label and the list of AI / human signals. Paste your own text to experiment. |
| **Reset all settings** | Defaults restored (after confirmation). |

## 5. Real websites (spot checks)

Try a few pages and confirm nothing breaks (scrolling, clicking links, forms, comment boxes):

- A news article (e.g. BBC, The Guardian) — article body is one unit; captions/bylines ignored.
- Reddit thread — only post/comment bodies can be blocked; votes, usernames, reply buttons untouched.
- YouTube video page — only comments/description are analysed; the player is never touched.
- Google search — result snippets; an **AI Overview** (when shown) is blocked as “Labeled as AI-generated by this site” unless that option is off.
- X/Twitter — only tweet text.
- An infinite-scroll feed — new items are scanned as they load; the page stays responsive.
- Google Docs / Gmail — extension stays inactive (“Not available on this web app”).

Open DevTools → **Performance** on a long page while scrolling: scanning should appear only as short idle-time tasks.

## 6. Privacy check

DevTools → **Network** on any page: the extension makes **no** requests. `chrome://extensions` → *Details* → permissions: storage, activeTab, scripting, and site access for the content script.
